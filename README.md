# Site Eduardo Rodrigues Advocacia

Site institucional desenvolvido para um escritório de advocacia. Projeto real, entregue a um cliente.

🔗 **Site no ar:** eduardorodriguesadvocacia.netlify.app

## Sobre o projeto

Página única que apresenta o escritório, as áreas de atuação e as formas de contato, com visual sóbrio e leitura simples tanto no celular quanto no computador.

## O que eu usei

- HTML, para a estrutura da página
- CSS, para o visual e a adaptação a diferentes telas
- Netlify, para a publicação

## Estrutura

```
index.html    página principal
imgs/         imagens do site
```
